# Third-party components

- InsightFace: https://github.com/deepinsight/insightface — source code and pretrained model permissions are separate. This project uses the existing installed buffalo_l model; no model is relicensed here.
- Silent-Face-Anti-Spoofing / MiniFASNet: https://github.com/minivision-ai/Silent-Face-Anti-Spoofing — upstream notices and license remain in models/LICENSE and models/SOURCE.txt.
- JPHoliday 1.0.3: https://github.com/Lalcs/jpholiday — MIT, copyright notice reproduced in docs/licenses/JPHoliday-LICENSE.txt. Used for Japanese national holiday classification.
- FastAPI, Uvicorn, NumPy, OpenCV, ONNX Runtime, PyTorch and dependencies retain their respective upstream licenses. Installed dependencies are not relicensed by this application.

The demo contains artificial business records and no pre-enrolled employee face photos or biometric templates.
