# Face Attendance Web 機能仕様 v1.0.0

## 構成

店舗端末のブラウザでカメラ撮影・表示・ボタン操作を行い、Pythonサーバーで顔検出・特徴抽出・照合・ライブネス・勤怠処理を行います。SQLiteを保存先とし、本社画面はデスクトップ、店舗画面はタブレット・Laptop・iPhoneでの利用を想定します。

## ロール

| ロール | 主な操作 |
|---|---|
| 一般従業員 | 共用端末の顔認証と打刻、業務連絡の確認 |
| manager（店舗責任者） | 担当店舗の閲覧、修正申請、従業員関連申請、業務連絡 |
| hq（本社担当者） | 全店舗の管理、承認、直接確定、集計・CSV・バックアップ、manager権限管理 |
| admin（本社管理責任者） | hqの操作に加えてhq権限管理、店舗・共通パスワード・システム設定、DB復元 |

管理ロールは従業員IDに紐づけます。権限保持者は従業員一覧と権限保持者一覧の両方に表示します。adminの付与・剥奪はサーバーコマンド限定。最後の有効なadminは降格不可。画面だけでなくAPIでも権限と担当範囲を検証します。

## 店舗・従業員

- 店舗コードは登録順に00001から増加。
- 従業員番号は店舗コード5桁＋店舗内識別番号4桁。識別番号は0001から採番。
- 異動後も番号は不変、使用済み番号は再利用しない。99999店舗・店舗ごと累計9999件で採番を停止して案内。
- 氏名・読み仮名の編集、番号・氏名の部分一致検索。
- 新規登録・写真更新では正面マスクなし／ありの2枚。各写真にちょうど1人の顔を必要とする。
- 退職時は申請・承認で停止し、現用の顔写真・特徴を削除。勤怠・申請履歴は保持。再入社は同じ番号で再開。

## 認証と打刻

- InsightFace buffalo_lによる顔検出・特徴抽出と、登録ベクトルとの照合。
- MiniFASNetによるライブネス判定。精度はカメラと環境に依存する。
- 複数人では最大の顔を対象とし、2番目の顔面積が最大の80%以上なら打刻しない（設定可能）。
- 成功結果の受信後5秒間有効。約4秒の開始間隔で更新し、更新待ちも直前の有効な結果を保持。
- ボタン操作時は新画像で同じ本人を再確認。期限切れでも操作意図は受け付け、新しく本人確認した場合のみ記録。
- 同日複数回出退勤、勤務中の休憩開始、休憩中の休憩終了。休憩中の退勤は拒否。
- 二重打刻を防ぎ、通信が切れた場合は要求IDで結果照会。
- 端末時刻を記録し、サーバー受信時との差が2分以上なら拒否。

## 修正・承認・直接確定

店舗責任者は担当店舗の修正を申請。本社が確認して承認・差し戻しを行います。承認前の取り消し・内容調整・再申請に対応します。

hq以上は従業員登録、基本情報修正、勤怠修正を直接確定可能。それ以外の申請では申請者本人の承認を拒否します。直接確定でも検証と履歴を残します。

所属変更・写真更新・利用停止／再開の既存申請を保持します。未来の異動・応援予定は対象日に打刻がなければ本社が直接変更可能。応援は対象日の打刻前なら取り消し可能です。

## 業務連絡・勤務状況

宛先・期間を指定し、全従業員の一括選択、掲載取り下げ、確認ボタンによる確認記録を行います。確認人数から氏名・確認状態・確認日時を開きます。本文編集では既読を解除しません。

店舗責任者ホームは勤務中・休憩中の氏名・状態のみ。選択先では今回の出勤時刻、実働、累計休憩、総勤務、現在の休憩経過時間を表示。同日の複数勤務の累計は表示しません。

## 集計と保守

総勤務24時間超を要確認とし、修正は店舗責任者の申請と本社承認、または本社の直接確定で反映します。

月次で出勤日数・回数・実働・総勤務等を集計し、CSVを本社のみ出力可能。過去月の修正差分は受理月へ反映し、特別出勤として区別。減算しきれない勤務時間は次月以降へ繰り越します。給与計算自体は行いません。

CSVは毎日3時にバックアップし30日後に独立削除。未実行は次回起動時に補完。SQLiteは月次CSV出力時に保存し、年単位の世代は年度完了・新しい正常なバックアップを確認して翌年12月31日以降に削除します。現用DBの履歴は削除しません。

操作ログをSQLiteに保存し、対象操作では実行者・日時・対象・変更前後を記録します。保持期限や全ログ閲覧画面は実装していません。

## パスワードとログイン

個人・店舗共通とも6文字以上。個人初期値123456、権限保持者は初回・リセット後に変更必須。店舗入口と本社入口を分離し、Cookieも分離します。店舗責任者は5分の無操作でログアウト。本社は30分を初期値として本人が変更可能です。
