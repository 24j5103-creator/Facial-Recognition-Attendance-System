# 更新と復旧

公開パッケージには実行環境・現用DB・ログ・接続先設定を含めません。ダミーの従業員情報は `manage.py init --demo` で生成できます。

既存環境を更新する場合はサーバー停止・コードとDB退避後にプログラムを差し替え、変更された依存関係を導入してください。現用の `data` と `.venv` を公開パッケージの内容で初期化しないでください。`init --demo` は空のDB専用です。旧版DBからの自動移行は提供していません。

新規環境はREADMEの初期設定手順を使用してください。部署・店舗の共通パスワードは設定時に自分で入力します。実際の接続先・IP・SSH設定・HTTPS設定は各運用環境で管理し、公開リポジトリに保存しないでください。

旧版に戻す場合、退避したプログラムとDBをセットで復旧します。v3同士のDB復元はadminのバックアップ画面から実行できます。
